# Native Villages - Project Brief

## Project Overview
Native Villages is a Minetest mod that enhances the game world by adding procedurally generated villages, creatures, and structures across different biomes. The mod automatically places village settlements, wildlife, and decorative elements during world generation to create a more immersive and populated game environment.

## Core Requirements
- **Procedural Generation**: Automatically place villages, buildings, and creatures during world generation
- **Biome-Specific Content**: Different villages and creatures for each biome (grassland, desert, savanna, arctic, lake, jungle)
- **Multi-Language Support**: Internationalization using intllib for multiple languages
- **Performance Optimized**: Efficient world generation that doesn't impact game performance
- **Minetest Compatibility**: Support for Minetest 5.x and later versions

## Project Goals
1. Create diverse, immersive village environments that enhance gameplay
2. Provide educational value by showcasing different cultural architectures and lifestyles
3. Maintain high performance standards for smooth gameplay
4. Ensure mod stability and compatibility across Minetest versions
5. Build a maintainable codebase following Lua and Minetest best practices

## Success Criteria
- Villages generate naturally in appropriate biomes
- Creatures spawn and behave realistically
- No performance degradation during world generation
- Clean, documented code following project conventions
- Active community support and maintenance

## Scope Boundaries
- Focus on world generation and content placement
- No gameplay mechanics modifications (hunger, combat, etc.)
- Compatible with existing Minetest mods and API
- Maintain separation between different biome implementations
