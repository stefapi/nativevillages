# If enabled, logs the resolution of every biome category and ground node
# list once all mods are loaded (see biomes.lua)
nativevillages.debug_biomes (Native Villages debug biomes) bool false

# If enabled, buildings are placed by the flatness aware engine of
# placement.lua (ground height sampled over the whole schematic footprint,
# cliff sites rejected) instead of the historical mapgen decorations.
# Disable it to fall back to the exact old register_decoration behaviour.
nativevillages.use_new_placement (Native Villages new placement engine) bool true

# Maximum ground height difference allowed under a building; a candidate
# site whose sampled ground heights differ by more than this is rejected
# (new placement engine only)
nativevillages.max_ground_diff (Native Villages max ground height difference) int 3 0 64

# Overall building density of the new placement engine, as a SURFACE
# density: expected candidate sites per generated map node. The expected
# number of candidate sites tried per generated chunk is
#   density * chunk area
# (6400 nodes on a standard 80x80 chunk), stochastically rounded, and
# hard capped at 64 sites per chunk for performance (past ~64 tries an
# 80x80 chunk is saturated anyway: it physically fits about 13 buildings
# of footprint 18x18 plus min_spacing).
# Reference values on an 80x80 chunk:
#   0.00035 (default, calibrated on the historical decorations) = ~2.2
#     candidate sites per chunk
#   0.001 = ~6.4 sites/chunk
#   0.01 = 64 sites/chunk (the cap)
#   0.1 and above = 64 sites/chunk: the chunk is saturated, raising the
#     density further cannot add more buildings
# Tried sites still have to pass the biome, ground node, altitude and
# flatness filters, so the number of PLACED buildings is at most (and
# usually below) the number of tried sites. Combine with
# relax_altitude=true to also cover plateaus and high ground.
# (new placement engine only)
nativevillages.placement_density (Native Villages placement density) float 0.00035 0.00001 1.0

# If enabled, widens the altitude band of every ground anchored building
# by 10 nodes below its historical y_min and 30 nodes above its y_max.
# The historical bands were tuned for sea level terrain (grassland 16-20,
# savanna 11-15, jungle 11-20, desert 26-30, ice 1-3) and reject EVERY
# ground above them, so plateaus and highlands never receive any village
# no matter how high placement_density is: with the historical bands the
# altitude filter, not the density, is the limiting factor there. Water
# anchored lake buildings keep their exact bed level either way.
# (new placement engine only; default false = historical behaviour)
nativevillages.relax_altitude (Native Villages relax altitude bands) bool false

# Swamp behaviour: the swamp biome family (swamp, swampz, alderswamp,
# bog, mangrove, ...) receives the grassland buildings re-registered as
# *_swamp variants, anchored like stilt houses: the site must stand in
# SHALLOW water (at most 3 nodes between the surface and the bed) inside
# the 0..10 altitude band, the flatness test compares the water surface
# instead of the muddy bed, and the schematic is anchored on the water
# surface so its 30 node foundation emerges from the swamp (automatic
# with the default offset).
#
# Minimum empty space (nodes) enforced around every building placed by
# the new engine: a candidate site whose footprint expanded by this
# margin overlaps the footprint of an already placed building is
# rejected. Prevents overlapping buildings inside a chunk and across
# neighbouring chunks (new placement engine only; the historical
# decorations and the buildings of other mods are not covered)
nativevillages.min_spacing (Native Villages minimum building spacing) int 4 0 32

# If enabled, every candidate site is logged when it is generated:
# accepted (coordinates, footprint AABB, rotation), rejected because of
# a collision with a registered footprint, or rejected because the
# ground is not flat enough; plus one recap line per generated chunk
# (sites tried, accepted, and the rejections by reason: no matching
# drawing, not flat, collision, and the failed draws by ground, biome,
# altitude, open water) so you can see exactly where the tried sites go
# and what to tune. Lets you confirm live in-game that the
# anti-collision engine is running (see also the "placement engine
# ACTIVE/DISABLED" line logged once at startup)
nativevillages.debug_placement (Native Villages debug placement) bool false

# If enabled, the generic grass ground nodes of the placed schematics are
# replaced at placement time by the surface node of the actual biome the
# building is anchored in (see soil_replacement.lua); disable to keep the
# schematic soils untouched
nativevillages.adapt_soil (Native Villages adapt building soil to biome) bool true

# If enabled, every building placed by the new placement engine is
# deterministically populated right after placement: one inhabitant per
# bed (male/female alternated), one mob per native trigger node
# (barrel, hookah, hangingfish, ...) and one villager per anvil, all
# capped at 8 entities per building (see spawn.lua). The statistical
# mobs:spawn channel keeps running either way, its neighbours lists
# being enriched with the bed nodes of the running game; disable to
# rely on the statistical channel only (historical behaviour)
# Si activé, chaque bâtiment posé par le nouveau moteur de placement est
# peuplé de façon déterministe juste après sa pose : un habitant par lit
# (alternance homme/femme), un mob par nœud déclencheur natif (barrique,
# narguilé, poisson suspendu, ...) et un villageois par enclume, le tout
# plafonné à 8 entités par bâtiment (voir spawn.lua). Le canal
# statistique mobs:spawn continue de tourner dans tous les cas, ses
# listes de voisins étant enrichies des nœuds de lit du jeu en cours ;
# désactiver pour ne compter que sur le canal statistique
# (comportement historique)
nativevillages.deterministic_spawn (Native Villages deterministic building population) bool true
